# Лабораторная работа №1: Сбор параметров операционной системы

Скрипт на языке Python для автоматического определения операционной системы (Linux / Windows), сбора ключевых системных характеристик и экспорта полученных данных в файл формата JSON.

---

## Описание работы

Скрипт выполняет последовательную обработку данных:
1. **Определение платформы:** с помощью функции `platform.system()` определяется тип текущей ОС.
2. **Сбор универсальных параметров:** собираются характеристики, доступные на любой поддерживаемой ОС через кроссплатформенные API Python (сетевые идентификаторы, процессорные ядра, внешний IP).
3. **Сбор платформозависимых параметров:**
   * **Linux:** сбор информации об аптайме, модели процессора, оперативной памяти и диске через виртуальную файловую систему ядра (`/proc`) и вызовы стандартов POSIX.
   * **Windows:** сбор данных о версии сборки, модели процессора и рабочем каталоге через вызовы `platform` и `os`.
4. **Экспорт:** объединенный словарь сериализуется и сохраняется в файл `result.json` с форматированием (отступами).

---

## Обоснование выбора модулей

В соответствии с учебными требованиями:
* **Сторонние утилиты ОС не используются.** В коде полностью отсутствуют вызовы `subprocess`, `os.system` и выполнение системных команд (`uname`, `lscpu`, `free`, `df`, `ipconfig`, `curl`).
* **Использована только стандартная библиотека Python.** Установка внешних библиотек через менеджер пакетов (`pip`) не требуется.

### Задействованные стандартные модули:
* **`platform`** — кроссплатформенное определение типа ОС, архитектуры, версии ядра и сборок. Для Linux используется функция `platform.freedesktop_os_release()` (стандарт freedesktop).
* **`os`** — получение количества ядер процессора (`cpu_count`), текущего рабочего каталога и низкоуровневых системных параметров Linux через вызовы `os.sysconf` (размер страниц памяти).
* **`shutil`** — измерение емкости и свободного места на диске (`shutil.disk_usage`) без платформенных утилит.
* **`urllib.request`** — выполнение легковесного HTTP GET-запроса к публичному сервису Яндекс Интернетометр для определения внешнего IPv4-адреса без установки библиотеки `requests`.
* **`uuid`** — вычисление MAC-адреса сетевого интерфейса через `uuid.getnode()` без вызова сетевых утилит ОС.
* **`getpass`** — кроссплатформенное получение логина текущего пользователя.
* **`time`** — определение локального часового пояса устройства.
* **`json`** — форматирование и сохранение итоговых данных.

## Перечень собираемых параметров

### 1. Универсальные параметры (собираются на любой ОС)
* `os_type` — наименование операционной системы (`platform.system`).
* `hostname` — сетевое имя компьютера (`platform.node`).
* `architecture` — аппаратная архитектура процессора (`platform.machine`).
* `cpu_cores` — число доступных логических ядер (`os.cpu_count`).
* `current_user` — имя пользователя, запустившего скрипт (`getpass.getuser`).
* `timezone` — системный часовой пояс (`time.tzname[0]`).
* `mac_address` — MAC-адрес сетевого адаптера, преобразованный в шестнадцатеричный вид (`uuid.getnode`).
* `public_ip` — внешний IP-адрес пользователя, полученный от сервиса `https://ipv4.internet.yandex.net/api/v0/ip`.
* `python_version` — версия используемого интерпретатора Python (`platform.python_version`).

### 2. Специфичные параметры для Linux
* `distro` — дистрибутив Linux (считывается из `freedesktop_os_release` или файла `/etc/os-release`).
* `kernel` — версия ядра Linux (`platform.release`).
* `cpu_model` — точное наименование модели процессора (парсинг `/proc/cpuinfo`).
* `uptime_hours` — время непрерывной работы ОС в часах (считывание первого значения `/proc/uptime`).
* `ram_total_gb` — общий объем оперативной памяти в гигабайтах, рассчитанный через системные страницы `os.sysconf("SC_PAGE_SIZE")` и `os.sysconf("SC_PHYS_PAGES")`.
* `disk_total_gb` — общий объем корневого раздела `/` в гигабайтах (`shutil.disk_usage`).
* `disk_free_gb` — свободный объем на корневом разделе `/` в гигабайтах (`shutil.disk_usage`).

### 3. Специфичные параметры для Windows
* `windows_release` — мажорная версия/релиз Windows (`platform.release`).
* `windows_version` — полный номер сборки (build) системы (`platform.version`).
* `processor` — идентификатор и архитектурное семейство процессора (`platform.processor`).
* `working_folder` — текущая рабочая папка, в которой запущен скрипт (`os.getcwd`).

## Запуск скрипта

Скрипт не требует установки дополнительных зависимостей.

### Linux / macOS:
```bash
python3 lab1.py
```

### Windows:
```cmd
python lab1.py
```

После выполнения в текущей директории создается файл `result.json` с собранными параметрами.
